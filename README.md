Projeto para Armazenando dados com anexo(fotos) utilizando o Microsoft Azure

Utilizado a Liguagem de Programação Python com as seguintes bibliotecas
- Streamlite (Geração formulário)
- BlobServiceClient
- pymysql
- uuid
- json

Feito criação de Grupo de Recursos com o Recursos a Seguir
- SQL Server
- Banco de Dados SQL
- Conta de Armazenamento

Versionamento
- Utilizando o Git para adicionar repositório no Github
